# style-mingchao（当年明月 / 明朝那些事儿 写作风格）

由 `style-distiller` 蒸馏生成。所有规律均记录**动作**而非原句。

> ⚠️ **覆盖率声明**：本 skill 融合两类来源——
> (A) **全本报告值**：原博主对 148 万字全本蒸馏的硬数字（括号旁白 2780 处、15 字内短句成段 3912 段、作者在场 2.1/千字），可信度高；
> (B) **真实样本印证**：本仓库 `examples/style-mingchao/` 附带的 `mingchao-realrun/` 对公开可获取原文「引子+童年」(1,949 字，覆盖率 0.13%) 做的真实扫描，用于印证与补遗。
> 凡未被 (A) 或 (B) 支撑的项，标「软」，待用户提供全本 txt 后由 style-distiller 重蒸补全。

**铁律**：学的是动作，不是抄句子。不得复制原书语句、比喻、绰号；只能套用下面的规律。

## 二、第一层 · 管句子
- [硬] 补一句短旁白 → 用括号挂在句尾；括号内字数 ≤ 15，超限则独立成段。（报告值 2780 处；样本实测均 5.6 字，最短 2 字）
- [中] **人物档案短行**：开篇用逐行短句列「姓名/性别/民族/学历/职业/生卒…」定调，节奏明快。（样本内重复出现）
- [中] 想收住情绪 → 用一个短句单独成段，像闸刀切断积聚的情绪。（样本：「因为，他要吃饭。」）
- [中] 关键判断句放在段尾，起画龙点睛作用。
- [软] 口语反问制造在场：「怕了吧，那我不出去还不行吗？」

## 三、第二层 · 搭文章（含「定梁」）
- [硬] 每篇先定一根「梁」——一个人 / 一个词 / 一件道具 / 一份名单，所有材料挂其上；无梁则只是堆砌。（样本梁=朱元璋/朱重八）
- [中] 段落按「梁」的自然顺序排布，不强行编年。
- [中] 先抑后扬、先铺后收，结尾回扣梁。

## 四、第三层 · 何时收手（幽默边界）
- [硬] 丑角可以随意调侃。
- [硬] 悲剧人物、忠臣、真情，一字都不能油滑。
- [软] 庄重/出生异象/贫苦命运处用语克制，不调侃（样本方向一致，待全本验证）。

## 五、第四层 · 整书布局（连载 / 呼应）
- [中] 章末设悬念钩子，留读者往下看。（样本章末：「朱重八，来吧，命运之神正在等待着你！」）
- [软] 各章节前后呼应、埋设回收点。
- [软] 全书级环形收尾（仅出现一次，作参考非必选）。

## 六、心法（必须先认同再下笔）
1. 痛恨故作高深的文章——历史本身很精彩，都能写得好看。
2. 体裁不重要，要写「一部可以在轻松中了解历史的书」。
3. 绝大部分事件人物有史料来源，流行文学手法只是包装。
4. 幽默是调味不是主料；悲处不可轻佻。

## 七、写作与验收
1. 动笔前先确定本篇的「梁」。
2. 成稿后运行 `scripts/selfcheck.py <稿子路径>`，按输出 PASS/FAIL 验收；不达标回炉。
3. 自检项（基线）：括号字数 ≤15（报告值）、作者在场 ≥2.1/千字（报告值）、短句比例、书名号次数、收手边界（悲剧/忠臣段无油滑词）。
