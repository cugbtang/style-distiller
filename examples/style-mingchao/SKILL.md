# style-mingchao（当年明月 / 明朝那些事儿 写作风格）

本 skill 由 `style-distiller` 依据公开蒸馏报告重建生成。所有规律均记录**动作**而非原句。

> ⚠️ **来源与覆盖率声明**：本 skill 的数值与示例规律来自原作者公开的蒸馏报告（公众号《我用 WorkBuddy 把 375 章〈明朝那些事儿〉蒸成 43 条写作规律》），并非对 148 万字全本的独立重扫。标注「报告值」的项可直接信任；标注「待重蒸补全」的项需在你提供全本 txt 后由 style-distiller 重新扫描填充。

**铁律**：学的是动作，不是抄句子。不得复制原书语句、比喻、绰号；只能套用下面的规律。

## 一、八维画像速查（来自扫描统计）
| 维度 | 该风格特征 | 关键数字 |
|------|------------|----------|
| 句式节奏 | 大量短句独立成段，断情绪如闸刀 | 15 字内短句独立成段 3912 段（报告值） |
| 段落结构 | 单句成段切割情绪 | 同上 |
| 词汇偏好 | 口语化讲史，专名带书名号 | 书名号高频（待重蒸补总数） |
| 叙事视角 | **作者必须在场**，常跳出直接与读者对话 | 直接对话 2.1 次/千字（报告值） |

## 二、第一层 · 管句子
- [硬] 补一句短旁白 → 用括号挂在句尾；括号内字数 ≤ 15，超限则独立成段。（报告值：括号旁白 2780 处）
- [硬] 想收住情绪 → 用一个短句单独成段，像闸刀切断积聚的情绪。（报告值：3912 段短句成段）
- [中] 关键判断句放在段尾，起画龙点睛作用。
- [中] 口语助词与短反问穿插，拉近与读者距离。

## 三、第二层 · 搭文章（含「定梁」）
- [硬] 每篇先定一根「梁」——一个人 / 一个词 / 一件道具 / 一份名单，所有材料挂其上；无梁则只是堆砌。
- [中] 段落按「梁」的自然顺序排布，不强行编年。
- [中] 先抑后扬、先铺后收，结尾回扣梁。

## 四、第三层 · 何时收手（幽默边界）
- [硬] 丑角可以随意调侃。
- [硬] 悲剧人物、忠臣、真情，一字都不能油滑。
- [中] 开玩笑要看打在谁身上、落在什么身上。

## 五、第四层 · 整书布局（连载 / 呼应）
- [中] 章末设悬念钩子，留读者往下看。
- [中] 各章节前后呼应、埋设回收点。
- [软] 全书级环形收尾（仅出现一次，作参考非必选）。

## 六、心法（必须先认同再下笔）
1. 历史可以很好看——把人当人写，不当符号写。
2. 作者要在场，与读者并肩看戏，而非高高在上说教。
3. 幽默是调味，不是主料；悲处不可轻佻。
4. 先共情，再下笔；不认同的写法宁可不用。

## 七、写作与验收
1. 动笔前先确定本篇的「梁」。
2. 成稿后运行 `scripts/selfcheck.py <稿子路径>`，按输出 PASS/FAIL 验收；不达标回炉。
3. 自检项（基线来自报告值）：短句比例、括号字数 ≤15、书名号次数、作者在场 ≥2.1/千字、收手边界（悲剧/忠臣段无油滑词）。
